# Twonara

Twonara is a simple, mobile-first website for couples to discover places and build date plans.

## Product areas
- Customer website
- Business / Post Ad portal
- Admin panel

## Main customer categories
- Do
- Eat
- Privacy
- Relax
- Stay

## Build plan

### Phase 1 — Customer homepage ✅
- Location selector / search
- Do, Eat, Privacy, Relax, Stay tabs
- Friendly discovery cards
- Simple mobile navigation
- Date Plan entry point

### Phase 2 — Explore & place details
- Search and filters
- Category listing pages
- Place detail page
- Save / favorite
- Add to Date Plan

### Phase 3 — Date Planner
- Create plan
- Add and reorder stops
- Date / time
- Estimated budget
- Share plan

### Phase 4 — Customer accounts
- Sign up / login
- Saved places
- Saved plans
- Reviews

### Phase 5 — Business / Post Ad
- Business account
- Post listing
- Listing status
- Ad plans

### Phase 6 — Admin
- Review and approve listings
- Manage users, categories and ads
- Reports and moderation

### Phase 7 — Backend & launch
- Supabase database/auth/storage
- Maps/location
- PayHere
- Cloudflare deployment

## Local development
