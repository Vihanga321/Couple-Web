# Twonara

Twonara is a simple, mobile-first website for couples to discover places and build date plans.

## Product areas
- Customer website
- Business / Post Ad portal
- Admin panel

## Main customer categories
- Do
- Eat
- Privacy
- Relax
- Stay

## Build plan

### Phase 1 — Customer homepage ✅
- Location selector / search
- Do, Eat, Privacy, Relax, Stay tabs
- Friendly discovery cards
- Simple mobile navigation
- Date Plan entry point

### Phase 2 — Explore & place details ✅
- Search across places and experiences
- Do, Eat, Privacy, Relax and Stay filters
- Open-now filter
- Recommended, top-rated, nearest and budget sorting
- Responsive Explore results
- Full place detail view
- Save / favorite places
- Add / remove places from Date Plan
- Mobile-friendly detail layout

### Phase 3 — Date Planner ✅
- Create and name a date plan
- Choose the date
- Add places directly from Explore or Place Details
- Reorder stops
- Choose a time for every stop
- Remove stops
- Estimated budget summary
- Approximate combined distance
- Add more stops from the planner
- Share the plan with Web Share / clipboard fallback
- Responsive mobile date-planner layout

### Phase 4 — Customer accounts
- Sign up / login
- Saved places
- Saved plans
- Reviews

### Phase 5 — Business / Post Ad
- Business account
- Post listing
- Listing status
- Ad plans

### Phase 6 — Admin
- Review and approve listings
- Manage users, categories and ads
- Reports and moderation

### Phase 7 — Backend & launch
- Supabase database/auth/storage
- Maps/location
- PayHere
- Cloudflare deployment

## Local development

```bash
npm install
npm run dev
```

After pulling a new phase, restart the Vite dev server if needed.
